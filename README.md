# Бот «Рабочие смены»

Telegram-бот, который принимает **скриншот таблицы смен на месяц**, распознаёт
сотрудников, дневные/ночные смены, отпуска и выходные, а потом по запросу
показывает, рабочий день или нет.

Поддерживается таблица как в `img.png`: сотрудники в шапке, дни месяца слева,
коды `Д` / `Н` / `нм`, пустые ячейки — выходной, жёлтые блоки — отпуск,
голубые строки — выходные/праздники, справа две колонки контрольных сумм,
слева повёрнутая подпись месяца («Ноябрь»). Год на картинке может
отсутствовать — бот подставит текущий и даст его изменить.

## Возможности

- Распознавание таблицы локально, через Tesseract + OpenCV (без внешних API).
- Загруженные картинки не сохраняются: обрабатываются во временной папке и удаляются.
- Проверка распознанного по контрольным суммам «Дневных/Ночных смен».
- Если скриншот обрезан, все даты месяца всё равно проставляются:
  отсутствующие дни получают статус «❔ нет данных» и доступны для ручного
  заполнения.
- Пока идёт распознавание, чат блокируется: бот пишет «⏳ Ожидайте…» и
  принимает только отмену — кнопкой «❌ Отменить» или командой `/cancel`.
- Подтверждение результата и ручное исправление:
  - переименовать сотрудника;
  - изменить смену любого дня (Д / Н / ДД / отпуск / выходной);
  - добавить переработку `+П` к рабочей смене;
  - поправить месяц и год.
- Выбор сотрудника для чата с запоминанием («больше не спрашивать»).
- **Общие расписания:** создатель загружает таблицы, другие чаты
  подписываются по коду. У каждого чата свой выбранный сотрудник.
- Менять общее расписание может только создатель; подписчики только смотрят.
- Команды `/today`, `/date`, `/month`, `/months`, `/share`.
- `/reset` — меню сброса: сотрудник и запоминание, текущий ввод, отписка,
  удаление текущего месяца или всего расписания.
- **Напоминания о сменах** для создателя: режим «за день / в день / в конце
  смены», своё время и выбор типов смен (Д, Н, ДД). Напоминание приходит
  с кнопкой подтверждения и повторяется каждые 30 минут, пока её не нажат.
- `/today` показывает коллег по той же смене и кому передавать смену
  (`день → ночь → день следующего дня`). Если следующая смена попадает
  в незагруженный месяц — попросит загрузить его.
- Защита от перебора кодов: после 10 неудачных попыток чат блокируется.

## Быстрый старт (Docker)

1. Установите [Docker](https://www.docker.com/products/docker-desktop/).
2. Получите токен у [@BotFather](https://t.me/BotFather).
3. Создайте `.env`:

   ```bash
   cp .env.example .env
   ```

   и впишите `BOT_TOKEN=...`.

4. Запустите:

   ```bash
   docker compose up -d --build
   ```

5. Откройте бота, отправьте `/start`, выберите «🆕 Создать новое» и пришлите
   картинку с таблицей. После подтверждения бот выдаст код расписания.

Логи:

```bash
docker compose logs -f
```

Остановить:

```bash
docker compose down
```

База данных хранится в именованном volume `bot_data`. Сделать резервную копию:

```bash
docker run --rm -v shift_bot_data:/data -v "$PWD":/backup alpine \
  tar czf /backup/schedules-backup.tar.gz -C /data .
```

## Запуск без Docker

Нужен Python 3.13+ и установленный **Tesseract OCR с русским языком**.

### Linux

```bash
sudo apt-get install tesseract-ocr tesseract-ocr-rus
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # впишите BOT_TOKEN
python main.py
```

### Windows

1. Установите Tesseract для Windows (например, сборку UB Mannheim) и при
   установке отметьте русский язык.
2. Пропишите путь к `tesseract.exe` в `.env`:

   ```env
   TESSERACT_CMD=C:\Program Files\Tesseract-OCR\tesseract.exe
   ```

3. В PowerShell:

   ```powershell
   .venv\Scripts\activate
   pip install -r requirements.txt
   copy .env.example .env
   python main.py
   ```

Проверить, что Tesseract видит русский язык:

```bash
tesseract --list-langs
```

В списке должен быть `rus`.

## Настройки `.env`

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `BOT_TOKEN` | — | Токен от @BotFather (обязательно) |
| `DB_PATH` | `data/schedules.db` | Путь к SQLite-базе |
| `TZ` | `Europe/Moscow` | Часовой пояс для «сегодня» и дат |
| `TESSERACT_CMD` | — | Путь к tesseract, если его нет в `PATH` |
| `TESSDATA_PREFIX` | — | Путь к каталогу `tessdata`, если язык `rus` не находится |
| `MIN_IMAGE_WIDTH` | `600` | Минимальная ширина картинки для предупреждения |
| `MAX_IMAGE_MB` | `20` | Максимальный размер файла |

## Общие расписания и код

Расписание — это общая сущность с кодом, к которой может подключиться
несколько чатов. Все месяцы, загруженные создателем, видны всем подписчикам.

**Создать расписание (создатель):**
1. `/start` → «🆕 Создать новое».
2. Пришлите скриншот таблицы, проверьте распознанное, нажмите «✅ Всё верно».
3. Бот покажет код вида `K7M2-QX9P`. Передайте его другим чатам.

**Подписаться (другой чат):**
1. `/start` → «🔗 Подписаться по коду».
2. Отправьте код.
3. Выберите сотрудника, за которого будет показываться расписание.

Можно сразу дать ссылку с кодом:
`https://t.me/ваш_бот?start=K7M2QX9P` — при открытии чат подпишется
автоматически после проверки кода.

- Один чат — одна подписка. Переключиться можно через `/start <код>` —
  бот предложит подтверждение, либо `/unsubscribe` и затем `/start`.
- Смотреть код в любой момент: `/share`.
- Менять месяцы, дни и имена может **только создатель** (`/edit`, `/delete`,
  загрузка картинок). Подписчики получают отказ.
- Создателю можно выйти только удалив расписание: `/delete_workspace`.

### Защита от перебора кода

- Неудачные вводы считаются на чат и хранятся в базе.
- После **10 неудачных** попыток 11-я блокирует чат: бот один раз пишет
  «⛔ Чат заблокирован…» и дальше игнорирует любые сообщения этого чата.
- Успешный ввод кода сбрасывает счётчик.
- Разблокировка только вручную. Офлайн-команда (не команда бота):

  ```bash
  python -m bot.admin unblock <chat_id>
  ```

  В Docker:

  ```bash
  docker exec shift-schedule-bot python -m bot.admin unblock <chat_id>
  ```

  Или напрямую в SQLite:

  ```sql
  UPDATE chat_blocks SET blocked = 0, failed_attempts = 0 WHERE chat_id = <id>;
  ```

## Сброс (`/reset`)

Команда `/reset` открывает меню:

- **👤 Сотрудник и запоминание** — чат остаётся подписан, но бот снова
  спросит, для кого показывать расписание.
- **⌨️ Текущий ввод** — как `/cancel`.
- **🚪 Отписаться** — только подписчик; данные у остальных не меняются.
- **🗑 Удалить текущий месяц** — только создатель, у всех подписчиков.
- **💥 Удалить всё расписание** — только создатель, со всеми месяцами
  и подписками.
- **🔔 Напоминания** — только создатель, настройка напоминаний о сменах.

Опасные действия требуют подтверждения.

## Напоминания о сменах (`/reminders`)

Доступны только создателю расписания. Бот напоминает о сменах сотрудника,
выбранного создателем через `/employee`.

Настройки:

- **Когда напоминать:** за день до смены, в день смены или в конце смены.
- **Время:** для первых двух режимов задаётся вручную (`ЧЧ:ММ`, например
  `20:00`). В режиме «в конце смены» время считается по типу:
  Д — 20:00, Н — 08:00 следующего дня, ДД — 16:00.
- **Типы смен:** Д, Н и ДД включаются и выключаются отдельно.
- **Статус:** напоминания можно включить или выключить.

В напоминании есть кнопка **«✅ Напоминание получено»**. Если её не нажать,
бот повторит сообщение через 30 минут. После нажатия повторы прекращаются.
Повторы ограничены 6 часами после времени напоминания, чтобы бот не писал
бесконечно. Настройки и состояние отправки хранятся в SQLite, поэтому
перезапуск бота не создаёт дубли.

Если расписания на нужный месяц нет или выбранного сотрудника в нём нет,
напоминание пропускается.

## Как пользоваться

1. Отправьте `/start`. Если чат ещё не подписан, выберите «🆕 Создать новое»
   или «🔗 Подписаться по коду».
2. Создатель присылает скриншот таблицы (лучше файлом PNG/JPG) и подтверждает
   распознанное. Бот выдаёт код расписания.
3. Если что-то распознано неверно — «✏️ Исправить». Если всё верно —
   «✅ Всё верно». Затем выберите сотрудника и запомните выбор.
4. Если расписание поменялось и этого нет на картинке — нажмите
   «✏️ Изменить расписание» или отправьте `/edit`. Откроется календарь
   выбранного сотрудника: нажмите день и выберите новый статус.
5. Дальше:

| Команда | Что делает |
|---|---|
| `/start` | подписка по коду, создание нового или информация о текущем |
| `/today` | Смена сегодня, коллеги по смене и кому передавать смену |
| `/date 15` | 15-е текущего месяца |
| `/date 15.12` | 15 декабря |
| `/date 2026-12-15` | конкретная дата |
| `/date 15 декабря` | то же словами |
| `/month` | календарь текущего месяца |
| `/month 2026-12` | календарь конкретного месяца |
| `/share` | показать код расписания |
| `/employee` | сменить сотрудника / снова спрашивать при загрузке |
| `/months` | список загруженных месяцев |
| `/unsubscribe` | отписаться от общего расписания |
| `/edit` | изменить смены (только создатель) |
| `/edit 2026-12` | то же для конкретного месяца |
| `/delete 2026-12` | удалить месяц у всех подписчиков (только создатель) |
| `/delete_workspace` | удалить расписание целиком (только создатель) |
| `/reminders` | напоминания о сменах (только создатель) |
| `/reset` | меню сброса: сотрудник, ввод, подписка, напоминания, удаление месяца/расписания |
| `/cancel` | отменить ввод или распознавание картинки |
| `/help` | справка |

В календаре и после загрузки есть inline-кнопки: можно нажать на день и
посмотреть его статус. Кнопка «✏️ Изменить этот день» сразу открывает выбор
статуса: **Д (12ч) / Н (12ч) / ДД (8ч) / Отпуск / Выходной**, плюс
переключатель **`+П`** для переработки.

Команда `/month` показывает компактную сетку кнопок: на каждой кнопке число
дня и цветной кубик статуса (`5🟩`, `12🟦`, `7🟨`, `3⬜`). Если у смены есть
переработка, добавляется `+` (`5🟩+`). Нажатие на день показывает его статус,
кнопка «✏️ Изменить расписание» открывает редактор.

Обозначения: 🟩 12ч день · 🟦 12ч ночь · 🟪 8ч день · 🟨 отпуск ·
⬜ выходной · ➕ переработка · ❔ не распознано.

### Коды смен

| Код | Значение |
|---|---|
| `Д` | дневная 12-часовая смена, с ~08:00 |
| `Н` | ночная 12-часовая смена, с ~20:30 |
| `ДД` | 8-часовая смена |
| `НМ` | ночная 12-часовая смена в начале/конце месяца |
| `+П` | переработка, добавляется к рабочей смене: `Д+П`, `Н+П`, `ДД+П`, `НМ+П` |

В контрольных суммах `Д` и `ДД` считаются дневными, `Н` и `НМ` — ночными.
`+П` учитывается отдельным счётчиком и не меняет тип смены.

## Как это работает

- **OpenCV** находит линии сетки, границы колонок и строк.
- **Tesseract** (`rus`) читает имена сотрудников, подпись месяца, номера дней,
  коды смен и контрольные суммы.
- Цвет ячейки определяет отпуск (жёлтый) и выходные/праздники (голубые строки).
- Несколько вариантов предобработки каждой ячейки + выбор самого уверенного
  результата компенсируют ClearType-сглаживание и сжатие.
- Распознанные данные сверяются с колонками «Дневных смен» / «Ночных смен».
  Если суммы не сходятся, бот показывает, какие дни проверить.
- Всё распознанное сначала сохраняется как черновик и попадает в запросы
  только после подтверждения.
- После распознавания список дат дополняется до полного месяца. Дни, которых
  не было на скриншоте, помечаются как `❔` и их можно заполнить через `/edit`.
  При смене месяца в редакторе недостающие даты тоже добавляются автоматически.

```bash
pip install -r requirements-dev.txt

```

Интеграционный тест использует `img.png` и проверяет имена, дни, отпуска,

этот тест будет пропущен.

## Ограничения и решение проблем

- **Шаблон таблицы.** Первая версия рассчитана на такую же вёрстку, как
  `img.png` (Excel-скриншот с колонками сумм). Число сотрудников и дней
  определяется динамически, но совсем другие макеты могут потребовать
  доработки. Цветные заливки нужны для определения отпусков и выходных.
- **Tesseract не найден.** Установите его или укажите `TESSERACT_CMD`.
  В Docker он уже внутри.
- **Нет языка `rus`.** Установите `tesseract-ocr-rus` (Linux) или отметьте
  русский при установке Windows-версии.
- **Плохо распознаны дни.** Пришлите картинку файлом и в большем разрешении;
  ошибки можно поправить кнопкой «✏️ Исправить».
- **Бот не видит фото в группе.** У бота должен быть доступ к сообщениям:
  сделайте его администратором группы или отключите privacy mode у @BotFather.
- **«Сегодня» не совпадает.** Проверьте `TZ` в `.env`.
- **Доступ к общему расписанию.** Код — единственный ключ: кто знает код,
  может подписать чат. При этом менять расписание может только создатель.
- **Старая база данных.** Если обнаружена база прежнего формата (без
  `schedule_groups`), бот удаляет её при запуске и создаёт новую пустую.
  Данные старой версии не переносятся.
- **Заблокированный чат.** Разблокировка только вручную:
  `python -m bot.admin unblock <chat_id>` или SQL из раздела про коды.
