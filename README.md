# Бот «Рабочие смены»

Telegram-бот, который принимает **скриншот таблицы смен на месяц**, распознаёт
сотрудников, дневные/ночные смены, отпуска и выходные, а потом по запросу
показывает, рабочий день или нет.

Поддерживается таблица как в `img.png`: сотрудники в шапке, дни месяца слева,
коды `Д` / `Н` / `нм`, пустые ячейки — выходной, жёлтые блоки — отпуск,
голубые строки — выходные/праздники, справа две колонки контрольных сумм,
слева повёрнутая подпись месяца («Ноябрь»). Год на картинке может
отсутствовать — бот подставит текущий и даст его изменить.

## Возможности

- Распознавание таблицы локально, через Tesseract + OpenCV (без внешних API).
- Загруженные картинки не сохраняются: обрабатываются во временной папке и удаляются.
- Проверка распознанного по контрольным суммам «Дневных/Ночных смен».
- Пока идёт распознавание, чат блокируется: бот пишет «⏳ Ожидайте…» и
  принимает только отмену — кнопкой «❌ Отменить» или командой `/cancel`.
- Подтверждение результата и ручное исправление:
  - переименовать сотрудника;
  - изменить смену любого дня (Д / Н / отпуск / выходной);
  - поправить месяц и год.
- Выбор сотрудника для чата с запоминанием («больше не спрашивать»).
- Команды `/today`, `/date`, `/month`, `/months`, `/delete`.
- Отдельные данные для каждого чата: в группе — общее расписание чата,
  в личном чате — у каждого пользователя своё.

## Быстрый старт (Docker)

1. Установите [Docker](https://www.docker.com/products/docker-desktop/).
2. Получите токен у [@BotFather](https://t.me/BotFather).
3. Создайте `.env`:

   ```bash
   cp .env.example .env
   ```

   и впишите `BOT_TOKEN=...`.

4. Запустите:

   ```bash
   docker compose up -d --build
   ```

5. Откройте бота, отправьте `/start` и пришлите картинку с таблицей.

Логи:

```bash
docker compose logs -f
```

Остановить:

```bash
docker compose down
```

База данных хранится в именованном volume `bot_data`. Сделать резервную копию:

```bash
docker run --rm -v shift_bot_data:/data -v "$PWD":/backup alpine \
  tar czf /backup/schedules-backup.tar.gz -C /data .
```

## Запуск без Docker

Нужен Python 3.13+ и установленный **Tesseract OCR с русским языком**.

### Linux

```bash
sudo apt-get install tesseract-ocr tesseract-ocr-rus
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # впишите BOT_TOKEN
python main.py
```

### Windows

1. Установите Tesseract для Windows (например, сборку UB Mannheim) и при
   установке отметьте русский язык.
2. Пропишите путь к `tesseract.exe` в `.env`:

   ```env
   TESSERACT_CMD=C:\Program Files\Tesseract-OCR\tesseract.exe
   ```

3. В PowerShell:

   ```powershell
   .venv\Scripts\activate
   pip install -r requirements.txt
   copy .env.example .env
   python main.py
   ```

Проверить, что Tesseract видит русский язык:

```bash
tesseract --list-langs
```

В списке должен быть `rus`.

## Настройки `.env`

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `BOT_TOKEN` | — | Токен от @BotFather (обязательно) |
| `DB_PATH` | `data/schedules.db` | Путь к SQLite-базе |
| `TZ` | `Europe/Moscow` | Часовой пояс для «сегодня» и дат |
| `TESSERACT_CMD` | — | Путь к tesseract, если его нет в `PATH` |
| `TESSDATA_PREFIX` | — | Путь к каталогу `tessdata`, если язык `rus` не находится |
| `MIN_IMAGE_WIDTH` | `600` | Минимальная ширина картинки для предупреждения |
| `MAX_IMAGE_MB` | `20` | Максимальный размер файла |

## Как пользоваться

1. Пришлите скриншот таблицы. **Лучше файлом** (PNG/JPG): Telegram сжимает
   обычные фото, и мелкие `Д`/`Н` могут распознаться хуже.
2. Бот покажет распознанные данные и результат сверки контрольных сумм.
3. Если что-то не так — «✏️ Исправить». Если всё верно — «✅ Всё верно».
4. Бот спросит, для кого показывать расписание, и предложит запомнить выбор.
5. Если расписание поменялось и этого нет на картинке — нажмите
   «✏️ Изменить расписание» или отправьте `/edit`. Откроется календарь
   выбранного сотрудника: нажмите день и выберите новый статус.
6. Дальше:

| Команда | Что делает |
|---|---|
| `/today` | Смена сегодня |
| `/date 15` | 15-е текущего месяца |
| `/date 15.12` | 15 декабря |
| `/date 2026-12-15` | конкретная дата |
| `/date 15 декабря` | то же словами |
| `/month` | календарь текущего месяца |
| `/month 2026-12` | календарь конкретного месяца |
| `/edit` | изменить смены выбранного сотрудника в текущем месяце |
| `/edit 2026-12` | то же для конкретного месяца |
| `/employee` | сменить сотрудника / снова спрашивать при загрузке |
| `/months` | список загруженных месяцев |
| `/delete 2026-12` | удалить месяц |
| `/cancel` | отменить ввод или распознавание картинки |
| `/help` | справка |

В календаре и после загрузки есть inline-кнопки: можно нажать на день и
посмотреть его статус. Кнопка «✏️ Изменить этот день» сразу открывает выбор
статуса: **Дневная / Ночная / Отпуск / Выходной**.

Команда `/month` показывает компактную сетку кнопок: на каждой кнопке число
дня и цветной кубик статуса (`5🟩`, `12🟦`, `7🟨`, `3⬜`). Нажатие на день
показывает его статус, кнопка «✏️ Изменить расписание» открывает редактор.

Обозначения: 🟩 дневная · 🟦 ночная · 🟨 отпуск · ⬜ выходной · ❔ не распознано.

## Как это работает

- **OpenCV** находит линии сетки, границы колонок и строк.
- **Tesseract** (`rus`) читает имена сотрудников, подпись месяца, номера дней,
  коды смен и контрольные суммы.
- Цвет ячейки определяет отпуск (жёлтый) и выходные/праздники (голубые строки).
- Несколько вариантов предобработки каждой ячейки + выбор самого уверенного
  результата компенсируют ClearType-сглаживание и сжатие.
- Распознанные данные сверяются с колонками «Дневных смен» / «Ночных смен».
  Если суммы не сходятся, бот показывает, какие дни проверить.
- Всё распознанное сначала сохраняется как черновик и попадает в запросы
  только после подтверждения.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

Интеграционный тест использует `img.png` и проверяет имена, дни, отпуска,
выходные и все контрольные суммы. Если Tesseract с `rus` не установлен,
этот тест будет пропущен.

## Ограничения и решение проблем

- **Шаблон таблицы.** Первая версия рассчитана на такую же вёрстку, как
  `img.png` (Excel-скриншот с колонками сумм). Число сотрудников и дней
  определяется динамически, но совсем другие макеты могут потребовать
  доработки. Цветные заливки нужны для определения отпусков и выходных.
- **Tesseract не найден.** Установите его или укажите `TESSERACT_CMD`.
  В Docker он уже внутри.
- **Нет языка `rus`.** Установите `tesseract-ocr-rus` (Linux) или отметьте
  русский при установке Windows-версии.
- **Плохо распознаны дни.** Пришлите картинку файлом и в большем разрешении;
  ошибки можно поправить кнопкой «✏️ Исправить».
- **Бот не видит фото в группе.** У бота должен быть доступ к сообщениям:
  сделайте его администратором группы или отключите privacy mode у @BotFather.
- **«Сегодня» не совпадает.** Проверьте `TZ` в `.env`.
- **Данные чата.** Любой участник группы может загрузить и заменить
  расписание этого чата. Если нужно ограничить загрузку администраторами,
  это можно добавить отдельной настройкой.
